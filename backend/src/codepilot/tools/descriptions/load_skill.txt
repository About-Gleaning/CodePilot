加载一个已注册 skill 的完整 `SKILL.md`，以获取特定任务的操作指导。

使用规则：
- 当任务明显匹配某个可用 skill 的名称或描述时，应加载对应 skill。
- 每次调用只加载一个 skill，通过 `name` 指定 skill 名称。
- 该工具只读取并返回 `SKILL.md` 内容，不执行 skill 附带脚本，也不读取附加目录。
- 未找到指定 skill 时返回结构化错误。

适合场景：
- 用户点名某个 skill。
- 任务需要遵循 skill 中定义的专用流程、模板或验证步骤。
- 当前 system prompt 只提供 skill 摘要，需要完整说明才能继续。
