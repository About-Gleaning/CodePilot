写入用户的长期记忆，在用户明确要求“记住”某件事、规则或行为方式时使用。

使用规则：
- 只有用户明确表达“记住”“以后都按这个规则”“请记住我的偏好”等长期保存意图时才调用。
- 新增记忆时，传入 `old_string=""`，`new_string` 必须是精炼后的记忆内容。
- 修改已有记忆时，传入要替换的 `old_string` 和替换后的 `new_string`；`old_string` 必须能唯一匹配现有长期记忆。
- 只保存适合长期影响后续对话的偏好、规则、事实或行为方式。
- 不要保存临时任务、一次性提醒或当前会话内的普通上下文。
- 如果用户要求记住密码、Token、API Key 等敏感信息，应拒绝保存并说明原因。
