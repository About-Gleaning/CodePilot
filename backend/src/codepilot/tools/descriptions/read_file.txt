读取文本文件或图片文件。

使用规则：
- `file_path` 必须是绝对路径；workspace 外真实路径需要人工审批，或在全自动模式下直接读取。
- 也支持 `/path/from/workspace/root` 这类以 workspace 根目录为基准的绝对路径写法。
- 文本文件必须是 UTF-8 编码；可通过 `offset` 指定从第几行开始读取，默认 0。
- 文本文件可通过 `limit` 限制最多返回多少行；不传时返回从 `offset` 开始的全部文本。
- 文本输出是原始片段，不额外添加行号；复制内容用于 `edit_file.old_string` 时不要添加额外字符。
- 文件为空时返回成功，并明确提示“文件存在，但内容为空。”
- 文本输出最多保留 50000 个字符，超长内容会被截断。
- 图片文件支持 PNG、JPEG、WebP 和 GIF；读取成功后会作为图片附件提交给 LLM。
- 单张图片超过 5MB 时不会提交给 LLM，只返回文件信息和超限提示。
- 工具结果只返回图片元数据和受控本地路径，不返回图片 base64。

适合场景：
- 编辑前确认当前文件内容。
- 批量读取多个可能相关的只读上下文文件。
- 检查配置、源码、测试或文档片段。
- 查看图片内容，并让 LLM 基于图片继续分析。

失败情况：
- 文件不存在、未获准读取 workspace 外路径、目标是目录、非图片文件不是 UTF-8 文本或参数非法时，返回结构化错误。
