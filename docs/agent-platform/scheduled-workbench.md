# 定时任务全自动执行与会话工作台

## 已确认目标（2026-09-23）

保留独立 worker，不新增全局工作台；当前会话统一展示执行概览、成果、子 Agent 与执行结果。worker 普通工具审批自动通过，不提供 question，Hook 主动要求人工确认则失败。授权、readonly、目录、凭证、写租约仍须校验。主子轮数独立，不新增共享预算、暂停状态或跨重启工具检查点。

每次 worker 启动取最新 Agent 配置，运行中固定。旧任务模型及目录保持显式覆盖，新任务可跟随默认。同一任务最多一个待执行或活动 Run，重叠触发记录跳过。停用取消待执行，删除保留历史，不终止活动 Run。保留现有独立容量与一小时超时。

主进程预分配 Session，worker 通过 Run 专属凭据上报递增状态。终态不能倒退，原 Session 在 worker 确认退出及清理前禁止人工执行。服务重启中断并回收旧 worker、取消旧队列，不重放副作用；未来周期继续。结束后可在原会话人工发送新 Run。

当前会话使用有界增量读取展示 worker 持久化事件，不要求逐 Token 直播。成果只来自最终回复和结构化文件记录，不扫描目录、不额外调用模型。跨用户隔离与路径检查覆盖查询、停止和下载。

## 约束与性能

继续跳过 FlowDeck。保留历史格式，新字段使用兼容默认值；活动状态按 ID 索引，事件按字节游标有界读取，列表分页，禁止轮询扫描全部用户或重复解析完整历史。运行中定时会话只读但可停止。完成交付待验收，不等同于完整发布门禁。

## 实现记录

- 调度配置增加跟随模型和目录开关，默认关闭以兼容旧记录；新建表单默认打开。启动时读取最新可用配置和依赖，记录本轮实际 revision、模型、目录和轮数上限。
- 主进程先创建 Session 归属与索引，再启动 worker。上报使用本轮独立令牌、完整归属和递增序号；运行进度最多每三秒上报一次，状态不携带回复正文。
- worker 仍调用既有执行核心，普通审批自动处理，主子禁用 question；Hook 人工要求明确失败。BUILD 的 schedule_manage 在 worker 内注册受控代理，经本轮令牌转交主进程，调度文件保持单写者。子 Agent 请求携带自身 revision，不能在执行中换成最新权限。
- 主进程退出监控对已落盘会话终态做一次对账，通信失败不重跑模型或工具。终态会话记录刷新并 fsync；停止/超时先确定终态优先级，再取消 worker，必要时回收独立进程组及出生身份仍匹配的子进程。清理完成前不解除会话发送互斥。
- 重启结束旧活动及排队，不接续旧工具。停用取消 pending，删除保留运行历史，已运行 worker 不因删除而终止。
- 会话运行态返回 source、can_send、can_stop、轮数和阶段。定时会话读取持久化流的字节游标，单批最多 500 条或约 1 MiB（单记录硬上限 8 MiB），不建立高频 SSE。网页接续恢复网页 SSE 和人工规则，事件序号从已有末尾继续。
- 成果来自本轮回复与 write_file/edit_file/write_plan 的成功结构化结果。下载要求 Session 所有者、任务目录内普通文件、无符号链接且不超过 16 MiB；读取时重新核验。当前文件内容可随工作目录变化，不承诺文件历史快照。
- 当前会话内提供执行概览、成果、子 Agent 标签；已有任务看板为并行工作，本轮保留并兼容，未新建全局工作台。修复详情抽屉遮挡自动化入口、移动端入口不可达及浅色表单文字不清的问题。

## 性能与剩余边界

运行日志追加按偏移维护 Run/Session/活动索引，身份查询摊销 O(1)，调度只遍历活动集合；历史列表在缓存中排序并分页，首次加载需顺序建索引。事件轮询为 O(新增记录数)，跨日切换才查找该 Session 的后续文件。工作台仅处理有界消息及事件，停止边界的系统进程表检查为 O(系统进程数)，不放入日常轮询。

HTTP 取消只能结束本地等待；外部系统已经接受的操作可能仍生效。应用授权不是操作系统沙箱，任意脚本主动逃逸进程树不在本轮隔离承诺内。没有跨重启执行检查点、工具重放、共享 Token 预算或逐 Token worker 直播。真实 Provider/MCP 及发布级故障注入仍属于独立发布门禁。
