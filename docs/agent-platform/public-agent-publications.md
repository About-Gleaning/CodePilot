# Agent 主动发布与公共使用

日期：2026-09-22。状态：已完成本轮验证，交付待用户验收。按用户约定跳过 FlowDeck；不代表 CODE-53 发布门禁通过。

## 产品边界与生效规则

私人主 Agent 主动预览并发布为独立公共 Agent；非作者只读，使用者无需复制即可执行。主子配置、Skill、自定义 Hook 随 Agent 交付，不单独上架；工具、模型、MCP 和管理员 Hook 保留为平台依赖。不实现公共复制、差异更新、资源市场及物理清理。

| 内容 | 生效边界 |
| --- | --- |
| Agent 及子 Agent 配置 | 主动发布，新 Run 采用 |
| 公共 Skill | 保存当前文件集，下次 load_skill 读取，不保留历史版本 |
| 公共 Hook | 保存不可变内容，新 Run 固定主子 Hook 快照 |
| 工作目录和连接 | 按使用者独立保存；旧 Session 保持原目录 |

私人源修改不自动公开；再次发布保留已有公共 Skill／Hook 的当前内容，新增资源首次交付。当前 Run 的追加消息不切换配置。公共定时任务每次触发选定配置及 Hook，worker 校验发布记录和当前凭证；执行包格式 3，继续读取格式 1、2，私人定时任务规则不变。

## 存储与接口

公共数据位于平台目录 `publications/`，SQLite 索引维护发布物、配置发布记录、候选、幂等结果和个人使用设置。Skill 使用当前文件集，Hook 沿用不可变内容；存储作用域明确指定公共身份，不伪造私人用户。

`/api/agent-publications` 提供分页目录、详情、预览、确认、撤回、管理员下架、资源读取保存和个人使用设置。执行复用 Agent Manager 与发送接口。使用过的公共 Agent 进入个人工作台。

候选有效期 15 分钟，每用户最多 5 个。确认校验源配置、源资源、候选摘要和当前公共 revision／状态；资源准备完成后才公开入口。相同请求 ID 幂等返回原结果，竞争首次发布不能替换已发布身份。确认后删除候选，不将候选转为 Skill 历史版本。

单资源最多 100 文件、单文件 1 MiB、总量 4 MiB；发布总量最多 100 个配置资源、32 MiB 附属文件。发布不复制目录、连接身份、凭证、记忆正文及运行数据。文本和脚本检查已知秘密格式与私人路径，仍需作者检查预览，不能保证识别所有秘密。

## 隔离与安全

- 公共资源按所属发布物解析，私人 Agent 不能绑定公共附属资源 ID。
- 会话、记忆、附件、审批及容量按使用者隔离，作者无法读取他人执行数据。
- HTTP Hook 凭证绑定公共目标和字段映射，目标变化使旧绑定不可用，不回退作者或团队身份。
- Skill 编辑读取使用冲突标识，避免多文件读取混入并发保存；执行读取不固定 revision。Hook 文件按摘要读取。
- 撤回和下架禁止新执行，既有执行正常收尾；从新配置移除的资源保留供活动 Run 使用。撤回不是工具权限撤销。
- API 校验错误不回显请求正文；普通响应 no-store；SQLite 文件权限 0600，查询使用参数绑定。

## 界面与性能

一级导航增加公共 Agent；详情分为概览、配置与资源、我的使用设置。作者从私人配置发布，可在公共详情重新发布、撤回、编辑附属资源。公共资源不混入私人管理列表，也不增加资源反向关联入口。

标签切换保留资源草稿，失败保留输入，公共页面懒加载。发布文件处理与总字节数线性相关；目录索引分页，运行按身份读取，公共 Skill 不扫描全局目录，不增加后台更新轮询。
