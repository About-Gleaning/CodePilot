# 前端交互与设计语言重构

## 2026-09-24 仅委派 Agent 配置入口

Agent 首页统一展示当前用户可见的全部 Agent。支持 `direct` 的 Agent 继续展示根运行态和最新 Session；仅支持 `delegated` 的 Agent 使用同一模块网格展示委派配置摘要，点击模块直接进入配置页，不提供启动、新任务、会话入口或伪造的停止状态。内置与共享配置保持只读并可复制，个人配置保持可编辑；等待与运行数量仍只统计支持直接启动的 Agent。

本次只调整前端目录展示和路由入口，不修改 Agent API、运行时容量、委派权限或 Session 摘要协议。目录过滤复杂度保持 O(n)，排序保持 O(n log n)，仅委派 Agent 不触发逐项详情请求。

## 2026-09-23 Agent 模块化总览与独立交互页

本轮将已登录前端统一为编辑部式控制台：深墨导航、纸白工作面、橙色主操作、青绿运行状态和黄色人工等待。Agent 首页改为统一模块网格，不再按状态分栏；每个主 Agent 展示自身运行状态及最新 Session，点击后进入独立交互页。最新任务固定映射为 Session，一次 Session 可以包含多次 Run，不新增任务实体。

路由采用现有 hash 机制，不引入路由依赖：`#/agents` 为总览，`#/agents/new` 为新建，`#/agents/<agent_id>` 为 Agent 最新会话，`#/agents/<agent_id>/new` 为新会话草稿，`#/agents/<agent_id>/sessions/<session_id>` 为指定会话，`#/agents/<agent_id>/config` 为配置；资源管理继续使用 `#/skills`、`#/hooks`、`#/publications`，旧 `#/studio` 兼容迁移到总览。无效身份必须显示错误，不得静默选择其他 Agent。

首页仅消费 Agent 目录、低频运行态及新的批量最新 Session 摘要，不加载 Session 列表、完整 replay 或会话级 SSE。后端按当前用户一次扫描缓存摘要并聚合每个 Agent 的最新 Session，时间复杂度为 O(Session + Agent)、额外空间 O(Agent)；前端排序为 O(Agent log Agent)。进入交互页后才加载当前 Agent 的 Session 列表，并只为当前 Session 保留一条高频流。

全局左栏只承担一级导航、容量、主题和用户入口。Agent 模块删除内联派发、固定观察和停止快捷操作，仅保留进入详情、处理等待、启动及配置等必要入口。技能、Hook、公共 Agent 和 Agent 配置保留既有业务与保存边界，统一页面标题、工具栏、状态、错误、标签页和响应式布局。桌面使用均衡紧凑密度，900px 以下切换为同一业务 DOM 的移动抽屉。

## 目标与边界

本轮把 Agent Studio 收敛为安静、密集、状态优先的任务控制台。用户应先看到需要介入和正在执行的工作，再进入单个 Session 查看过程、成果与自动化。资源管理、Agent 配置和登录页使用同一套排版、颜色、控件与响应式规则。

本轮不修改 API、SSE、认证、权限、Agent 生命周期、配置保存边界和 Session 持久化语义，也不新增逐 Agent 详情请求。桌面与移动端继续复用同一业务 DOM。

## 交互决策

- 左侧导航负责产品一级入口与 Agent 选择；看板负责跨 Agent 状态扫描；会话详情以工作抽屉承载；会话与自动化继续放在上下文侧栏。
- 看板按等待处理、执行中、空闲、异常或停止排序。非空队列优先，空队列弱化，不隐藏任何状态。
- 看板顶部展示总数、等待、执行中和可用数量，数据只来自已经加载的 Agent 与运行态，时间复杂度 O(n)，空间复杂度 O(1)。
- 会话详情打开时提供明确遮罩与关闭入口。桌面端保留看板上下文，移动端使用全屏工作区；检查器层级始终高于遮罩。
- 保留所有既有可访问名称。图标按钮必须有 `aria-label` 和 `title`，键盘发送、审批和问题交互行为不变。

## 设计语言

- 方向：编辑部式任务控制台。深墨色导航与纸白工作面形成稳定边界，信号橙表示主要动作，青绿色表示可运行状态，黄色表示等待人工。
- 组件：页面分区保持无框，卡片仅用于可重复 Agent 和消息单元；圆角不超过 6px，避免嵌套卡片。
- 字体：中文正文使用系统可用的高质量黑体，标题使用宋体或衬线字体，运行标识使用等宽字体。关键文字不得小于 11px，不使用负字距或随视口缩放的字号。
- 动效：只保留抽屉、消息到达和状态变化；`prefers-reduced-motion` 下关闭非必要动画。
