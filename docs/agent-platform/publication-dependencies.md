# Agent 发布诊断与一次性依赖发布

日期：2026-10-09。工作项：CODE-72。状态：已实现，待用户验收。

## 目标与范围

发布检查汇总主 Agent 和一层委派的独立问题，展示可见资源、引用方、原因及建议。统一预览后一次确认发布未公开的本人代码工具、恢复本人撤回的公共工具，最后公开 Agent。正常公共版本不被私人修改覆盖；恢复使用原公共版本，影响所有引用它的 Agent。

不公开私人目录、连接、凭证、记忆或运行数据；发布检查不依赖作者运行凭证。不执行工具代码，不发模型请求，不后台自动续发。保留原公共 Skill／Hook 当前内容，不锁定 Skill 运行时版本。

## 接口与安全边界

预览新增严格布尔 include_dependencies，默认 false；既有确认字段保留。结构化 issues 包含安全资源信息、引用方和允许的动作。无权读取不泄露资源名称或归属，敏感内容错误不回显正文。

统一候选固定源配置、成员、最终公共内容、状态和动作。摘要只覆盖固定内容，进度单独保存；15 分钟有效期。每候选最多 100 个工具动作，新增工具与附属内容共用 32 MiB 上限，不占逐工具预览名额。

## 确认与重试

首次确认绑定请求 ID；工具步骤使用候选内稳定身份，工具变更与回执在同一工具事务提交。重试核对已成功步骤当前状态，后续撤回、禁用、更新不能凭旧回执再次公开。临时失败保留逐项结果，内容或权限变化要求重新预览。

最终按公共发布库→工具库获取写事务，复用事务内读取校验；全部依赖成功且与候选一致后才提交 Agent。部分成功不回滚已公开工具，首次失败不公开 Agent，重新发布失败保留原公共记录。重启不自动继续，仅人工重试。

## 实施与验证

1. 后端诊断与候选：覆盖依赖状态、公共旧版本冲突、附属资源和脱敏。
2. 工具事务回执与批量确认：覆盖部分失败、崩溃窗口、重复请求、并发变化及过期。
3. 前端统一预览与结果：覆盖结构化错误、一次确认、稳定重试及目标切换。
4. 执行后端回归、前端测试与生产构建，检查桌面和移动端，补齐实际证据。

时间复杂度 O(引用数＋读取字节数)，工具去重读取并设置整体上限；不新增全目录扫描或后台轮询。

## 实现补充与兼容

- 工具回执写入工具索引 publication_steps，候选请求归属与进度写入公共索引 candidate_attempts，均通过 CREATE TABLE/INDEX IF NOT EXISTS 自动初始化，无需新环境变量。部署前旧候选必须重新预览；旧客户端不传 include_dependencies 时不自动发布依赖。
- 同一工具的私人／公共 ID 映射去重，调用名冲突按最终公共版本检查。已撤回公共版本恢复只改变状态，不更新内容、调用名或私人凭证。
- 新 Skill 在发布前复用保存时的正文校验，损坏正文不能等工具已公开后才发现。已交付公共 Skill／Hook 读取当前内容，不覆盖私人编辑或恢复 Skill 历史版本。
- 状态、版本及权限变化要求重新预览；暂时存储错误可用原候选和请求 ID 重试。过期候选不能续发，返回保留的进度（若仍存在）。浏览器断开或服务重启后不会主动重放。
- 有界读取过程中累计工具与新增附属内容，超限立即停止，不先聚集全部超限内容。最终公共入口与工具状态按固定锁序提交；当前实现串行化公共发布确认，较大但有界的文件发布可能增加其他发布请求等待时间，不影响模型／工具执行线程。
