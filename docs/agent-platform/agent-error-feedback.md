## 行为契约

- Agent 文件加载保留安全的结构化错误：YAML、必填字段、类型、版本摘要、文件读取。未知异常不得直接输出异常字符串。
- 配置列表和详情通过 validation_issues 返回原因与 suggestion；启动与新 Run 在原 detail.code、message 旁增加 issues，保持已有错误码及 HTTP 状态。
- 保存请求的 schema 错误只暴露已声明字段，不回显 input、指令、凭证或解析器片段。原生 schema 校验原本没有业务错误码，现归类为 agent_config_invalid。
- 子 Agent 依赖错误标明当前用户可见的委派身份及 subagent_ids 字段，不查询其他用户名称。
- 页面展示失败操作、原因、处理建议；技术码折叠。配置入口不授予编辑权限，损坏或共享配置仍只读。旧接口错误继续兜底。
- 启动响应按 Agent 身份校验，切换后迟到的错误不能覆盖当前视图。错误展示 O(k)，复用已有依赖检查，不增加资源扫描或逐项请求。
