## 功能入口

Studio 导航增加独立 Skill、Hook 页面，地址分别为 `/#/skills`、`/#/hooks`。支持直接访问、浏览器前进后退和桌面／移动端导航。切换资源页保留当前会话、Agent 配置和资源编辑草稿；刷新页面时未保存修改会触发离开提醒。

Skill 页面支持个人创建、正文编辑、附带文件上传／下载／移除、复制、归档、搜索、分页和引用查询；共享 Skill 只读查看，可复制为个人版本。Agent 编辑页仅选择 Skill 并提供管理入口。

Hook 页面支持个人 Prompt、Command、HTTP 定义、脚本文件、参数、节点、顺序、超时及异常策略；平台定义只读。平台的服务端命令、目标和凭证配置不在详情中公开，复制后须补充自己的执行配置。Agent 类型仍明确不支持。凭证通过现有连接编辑器单独加密保存，复制 Hook 不复制连接身份或凭证。

## 存储与执行快照

个人 Hook 使用 `personal:<UUID>` 稳定身份。资源位于 `{codepilot_home}/users/<user_id>/hooks/<uuid>/`：`current.json` 保存当前指针和并发编辑 revision，`versions/<摘要>/definition.json` 保存不可变定义及文件摘要，脚本位于该版本的 `files/`。

一次保存提交完整定义和文件集，持文件锁校验 revision，先发布完整版本，再原子替换当前指针。定义上限 256 KiB；脚本只接收 UTF-8 文本，最多 100 个文件、单文件 1 MiB、总量 4 MiB。禁止绝对资源路径、路径穿越和符号链接逃逸；不自动安装解释器或依赖，不物理删除历史版本。

主 Agent 在 Run 开始解析身份、参数和版本；子 Agent 在派发时解析自己的资源。个人 Hook 只注册到当前上下文，实例不进入全局注册表。运行中更新不改变已选版本，归档阻止新执行。平台 Hook 保存定义摘要，worker 发现平台配置已变化时明确失败，不能静默换版。执行包兼容旧字段缺省，新快照包含个人 Hook 版本和平台 Hook 摘要，不包含秘密。

HTTP 连接绑定用户、Hook 身份、目标 URL 和 Header 字段映射摘要。更换目标或映射后，原连接不可继续使用；同一目标的无关描述修改不要求轮换凭证。撤销或轮换在后续调用前校验，没有个人连接到团队连接的自动回退。版本化目标定义使用按用户、身份、版本区分的 128 项缓存，调用时仍读取当前指针及连接状态。

## 节点和恢复

| 节点 | 行为 |
| --- | --- |
| `session.before` | 本次 Run／子上下文开始，位于第一轮之前 |
| `loop.before` | 本轮开始，位于压缩之前 |
| `llm.before` | 压缩之后、模型请求构造之前 |
| `llm.after` | 模型响应完成，工具执行之前；不能撤回已流式展示的文本 |
| `tool.before` | 平台权限和工具审批通过之后、工具调用之前 |
| `tool.after` | 工具结果已发生并发布之后；失败不能抹除工具结果 |
| `loop.after` | 本轮模型与工具流程结束，包含纯文本完成的最后一轮 |
| `session.after` | Run 收尾；用户停止时不启动外部收尾调用，不保证崩溃时执行 |

同节点按顺序、稳定 ID 串行运行。自定义工具 Hook 命中时，将该工具批次按原顺序串行处理，未命中保持原并行行为。平台权限检查先于插件，并且不可被插件修改。

人工请求在同一个异步调用栈中等待，保留下一 Hook、模型结果及工具批次位置；批准后继续剩余步骤，不重跑已经完成的操作、不重新消耗一轮。网页主会话的 Hook 请求独立于工具自动审批开关；子 Agent 和无交互 worker 明确失败。停止信号可打断等待。重启结束旧 Run，不恢复调用栈、不重放外部调用。

新协议的明确停止记录为 `CANCELLED/hook_stopped`；失败为 `FAILED`。保留旧平台 Hook 的内部结果适配和既有停止语义。既有取消、失败终态优先，收尾批准不会将已完成会话遗留为运行中。

## 外部协议

Prompt 仅支持三个前置节点，追加带 Hook 来源的 synthetic 上下文，不改原始 Agent Prompt。Command 使用 argv 数组，不拼接 shell；`@file:check.py` 引用当前版本内的受控文件，通常使用 `python3` 等解释器作为首个参数。外部可执行程序本身由运维维护，不承诺其文件内容随 Hook 固定。

Command 从标准输入读取 JSON，标准输出只输出一个 JSON 对象；HTTP 固定使用 POST，不跟随重定向，不使用隐式环境代理。两者输入、标准输出和标准错误各有 64 KiB 上限，默认超时 30 秒、最大 300 秒。

输入包含 `protocol_version=1`、调用身份、节点、Run／上下文、轮次、参数及当前节点的文本或工具信息。不提供整场历史、思维链、附件编码、配置对象或凭证对象；已知敏感字段过滤。自由正文与脚本由互信用户自行维护，过滤不等于通用数据防泄漏机制。

返回协议字段：

```json
{"protocol_version": 1, "action": "continue", "reason": "", "context": ""}
```

`action` 只能为 `continue`、`stop`、`fail`、`human` 中的一个；`context` 仅允许前置节点，`reason` 用于人工请求说明。未知字段、内部会话对象、工具调用、身份覆盖和任意事件均不接受。明确返回的控制动作不会被异常策略降级。

已知请求尚未发出的错误按异常策略处理。请求发出后超时、断连、非正常退出、超限或返回无效结果，标记结果不确定并失败，禁止自动重试。Command 只继承必要系统环境，使用原有工作区写入租约，取消回收整个进程组；HTTP 取消仅中断本地等待，不承诺撤销远端副作用。配置 Command Hook 是独立执行授权，不受 Bash 工具 readonly 策略包裹，也不提供 OS 沙箱。

## 资源和测试 API

- `/api/hooks`：分页列表、创建；`/{id}`：详情、带 revision 更新；`/{id}/files`：受控读取；`/{id}/archive`：归档；`/{id}/references`：当前 Agent 引用。
- `/api/skills`：补充搜索、状态过滤、详情、共享文件查看和引用查询；原保存与文件协议继续兼容。
- `/api/hooks/{id}/tests`：测试已保存版本；`/api/hook-tests/{id}`：查询；`/{id}/cancel`：取消。
- 测试使用合成输入、选定工作目录和明确连接，不创建 Agent Run，不调用其他 Hook。测试中的人工动作仅展示结果，不创建等待状态。
- 每用户最多 1 个、全服务最多 2 个活动测试，容量已满立即拒绝。持久化请求指纹和结果摘要，重复请求返回原记录；进程重启后的未完成记录标记中断，不重放。详细结果内存最多 20 项、5 分钟，磁盘不保存原始输入输出或秘密。
