# Python Tool 管理与分享

日期：2026-10-09。工作项：CODE-69。状态：已实现，待用户验收。

## 已确认目标

用户自主创建、测试、发布 Python Tool，其他用户在 Agent 配置中绑定公共工具。首版只支持同步 Python 函数 execute(arguments: dict) -> dict 和辅助 Python 文件，不自动安装依赖。代码可以访问文件及网络；部署边界是互信团队，不提供 OS 沙箱。

## 兼容契约

保留 BaseTool、ToolSpec、内置工具、MCP 服务授权及既有结果协议。新增 PythonCodeTool 适配器继续经过审批、Hook、写租约和工具事件。Agent 的 tool_ids 独立于旧 tools；缺省空数组，更新省略保留，显式空数组清空，null 拒绝。运行状态同步 tool_ids，运行快照记录 resolved_tool_versions。只读 Agent 禁用代码工具，默认串行、审批并获取写租约。

代码和文件不可变保存，私人修改不公开，主动发布生成公共身份。新执行采用最新发布，活动执行固定版本；私人委派派发时取快照，公共主子在根 Run 固定。撤回禁止新执行，管理员禁用阻断后续调用。Agent 发布前私人依赖必须已有公共身份，预览映射，确认复核，不修改私人配置。凭证归使用者，独立加密保存，以专用环境变量传递，不继承平台秘密。

## 实现决策

- 独立工具 SQLite 元数据索引用于分页；文件版本原子发布，摘要校验，不删除历史。
- 固定当前 Python 解释器在独立进程运行；stdin 为参数 JSON，stdout 为受控结果协议，用户 print 进入有界诊断流。代码只在测试或调用时导入。
- 默认超时 30 秒，上限 300 秒；输入、结果、诊断分别 64 KiB。取消及超时回收整个进程组。参数使用 JSON Schema 校验，不拼接 shell。
- 工具调用名称优先使用版本内的 call_name，旧版本缺省才使用 ID 派生保留前缀名称（CODE-71 修订）；冲突拒绝，私人工具仅当前用户可见，公共工具独立作用域。
- 执行包写格式 5，读格式 1—5；worker 比较配置时排除运行资源版本，再独立校验摘要与归属。
- 测试只允许已保存版本，幂等请求、限额、取消、重启后不重放。

## 性能与部署边界

目录使用 SQLite 分页读取元数据，运行时按身份和版本直接获取选定文件，不扫描全部工具。保存校验与摘要计算为 O(总文件字节数)，单次最多 100 文件、单文件 1 MiB、总量 4 MiB；进程输出按块读取并在 64 KiB 上限及时失败，避免无界缓冲。历史版本持久保留，需沿用部署备份和容量管理。

不自动安装依赖；工具使用部署 Python 中已有依赖。工作目录与写租约不限制用户代码的 OS 文件和网络访问，只适用于互信团队。公共工具更新属于作者提供的新代码，凭证字段变化要求重新配置。完整 CODE-53 发布门禁与真实 Provider／MCP 发布审计未在本轮执行；本轮回归不能声明源码发布通过。

## CODE-71 独立调用名称（2026-10-09）

已确认目标：展示名称与模型调用名称分开维护。工具定义新增 call_name，新建 HTTP／网页工具必须填写，例如 test_tool；长度 1—64，首字符为英文字母或下划线，其余仅英文、数字或下划线，禁止 mcp__、code_tool_ 保留前缀。工具详情、发布预览和 Agent 选择展示调用名称。授权、凭证和引用继续使用完整工具 ID。

兼容决策：旧版本缺少字段继续使用 ID 派生调用名，不自动迁移；旧客户端更新省略字段保留原调用名称，显式空值拒绝。私人保存后新执行取新名称，公共工具重新发布后生效；活动执行保持固定版本，历史会话与执行包不改写，不注册旧名称执行别名。

装配安全：配置解析提前检查代码工具之间及与平台工具的名称冲突；运行时注册再次检查代码工具与任何现有工具的冲突，双向注册顺序都不能覆盖。MCP 发现时遇到代码工具冲突应明确拒绝装配，不跳过冲突。名称校验为 O(名称长度)，字典冲突检查为 O(注册工具数量)，不扫描工具目录。
