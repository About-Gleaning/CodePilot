# 技能与执行钩子管理体验重设计

日期：2026-09-18。状态：已实现，待用户验收。用户明确要求跳过 FlowDeck；未执行完整发布门禁。

## 功能与入口

- 一级导航为 Agent、技能、执行钩子，桌面与移动端共用业务 DOM；折叠导航仍保留可访问名称。沿用 `#/skills`、`#/hooks` 和 `#/studio`。
- 管理页采用列表进入详情结构，搜索防抖 250 ms，分页查询。复制与归档位于更多菜单；归档确认包含当前引用信息。
- 技能默认编辑名称、用途和 Markdown 正文，支持预览。附带文件和只读引用情况分设页签，高级源码作为独立入口。保存后保留详情与保存状态。
- Hook 新建依次填写执行方式、触发时机、执行内容；已有资源直接分区编辑。提示型只显示支持的三个前置节点；其他类型保留完整节点与工具范围。
- 脚本型提供返回继续动作的 Python 示例、解释器、入口文件、参数及文件编辑器。特殊旧命令仍以原参数数组编辑。HTTP 目标与认证字段独立维护，真实凭证继续使用现有连接接口。
- 测试只针对已保存版本；编辑未保存时禁止测试。外部测试保持副作用确认，结果不确定明确提示且不自动重试。轮询串行，取消后的迟到响应不能覆盖终态。
- 技能和 Hook 页均不提供 Agent 选择及配置按钮，绑定和解绑只能从 Agent 配置发起；保留返回原配置的入口。资源保存不自动扩大 Agent 授权；往返资源管理不清除 Agent 配置草稿。

## 实现约束

独立的 SkillManagerPage 与 Agent 内的 SkillEditor 选择器分离。技能源码使用 YAML 文档解析器保存未知字段与注释，仅更新表单负责的字段；非法头部或非文本名称、用途禁止表单覆盖，需在源码修复。原文件协议、版本冲突和不可变版本机制继续沿用，无后端 API、执行协议或存储迁移。

资源页访问后保持挂载以保存当前草稿；敏感凭证不进入浏览器持久存储。资源详情与引用请求具有归属和取消边界，列表不逐项读取引用。关联列表在重新进入时刷新，避免配置 Agent 后仍展示旧引用。

技能管理及 YAML 依赖按页面懒加载。列表处理为 O(p)，文档解析和完整附件提交为受文件限制约束的 O(n)；代价是访问过的两个管理页在当前会话保留一份编辑草稿。未新增历史版本扫描、全资源轮询或服务端查询负载。

## 2026-09-22 Agent 配置精密控制台

Agent 配置由单个长表单调整为概览、指令、能力、运行、记忆、连接六个可自由切换的分区。桌面端使用左侧分区轨显示校验问题、待配置状态和选择数量；900px 及以下改为吸顶分区选择器，390px 使用单列字段和图标保存按钮。顶部固定显示名称、角色、revision、校验状态和未保存状态，复制与归档收进操作菜单。只读、共享、内置和无效 Agent 保留完整查看内容及复制入口，但不允许直接编辑或保存。

保存边界保持原协议：概览、指令、能力、运行、`memory_enabled` 和连接身份选择统一保存 Agent revision；记忆正文继续由记忆接口独立保存；个人凭证的新增、更换、验证和撤销继续由连接接口独立保存。`null` 表示继承、空数组表示明确不启用，前端切换模式不改写该语义。后端 API、Agent Markdown、revision 和资源授权逻辑均未变更。

能力选择器只对当前已加载目录执行已选优先排序、搜索和状态筛选，单次处理复杂度为 O(n)，空间复杂度为 O(n)，不新增请求、轮询或逐项详情读取。不可用状态、审批风险和授权结论仍完全来自能力目录，前端不自行推断。凭证字段保持密码输入，仅存在于连接编辑器的瞬时状态，不进入 Agent revision、配置摘要或浏览器持久化。

实现将通用的前端目录筛选收敛到 `AgentCapabilityPicker`，保留 `MemoryEditor`、`ConnectionEditor` 和 `SkillEditor` 原有请求逻辑。已确认旧 `AgentConfigDialog` 没有运行时入口后删除，同时移除仅服务该弹窗的孤立样式；未清理无关历史代码。
