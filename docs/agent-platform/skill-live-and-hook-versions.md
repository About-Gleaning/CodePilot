## Skill 行为

取消主、子 Agent 及 worker 的 Skill 版本固定。运行配置仅记录选择的身份，不再携带 Skill 版本表或空资源快照标志。每次 load_skill 校验已授权清单、用户归属、归档及请求路径后读取最新内容；已经进入模型上下文的旧内容不自动替换。正在进行的模型请求不受修改影响。

共享技能启动只读一级目录 SKILL.md 简介，不递归读取脚本、构建目录或附件，不再生成或读取 skill-snapshots。管理页为展示及复制而单独枚举文件，跳过 .git、.build、.venv、node_modules、__pycache__、.DS_Store，限制条目数；直接请求仍执行路径安全校验。

个人技能采用 current.json 指向当前文件集；写入独立临时内容目录，全部写入成功后原子发布指针，再删除旧内容。读取、发布、归档及清理共用资源级文件锁。content-* 是原子发布的存储目录，不是可选择的版本；每次成功保存只保留当前目录。正文和附件不出现部分发布。接口 revision 仅是编辑冲突标识，下载带旧 revision 返回冲突，不能读取旧历史。

旧个人存储首次访问时验证当前 manifest 和文件摘要，再迁移并清理 versions；失败不删除旧文件。旧执行包中两个废弃字段只在反序列化入口忽略，不保留运行时兼容分支。废弃共享快照目录不再使用；不在启动路径遍历或批量删除既有共享缓存。

## Hook 行为

version 保留 SHA-256 内容身份，revision 保留并发编辑校验，新增 version_number 与 updated_at。首次保存第 1 版；相同内容保存不修改编号、时间或 revision；内容修改递增，即使恢复旧内容也递增。归档不改变内容序号，复制从 1 开始。

旧记录当前内容视为第 1 版，更新时间未知时不展示；不扫描历史推断次数。编号属于当前保存修订，读取不同历史摘要时不能附带当前编号。前端显示第 N 版及更新时间，技术详情显示短摘要并支持复制完整值；Hook 执行快照、凭证绑定、测试协议均不变。
